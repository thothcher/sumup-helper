# Sum-up Helper

JavaScript, React, Next.js და Angular შეჯამებები ერთ ადგილას. ყოველი თემა ცხოვრებისეული მაგალითით, გაშვებადი კოდით და დემოთი, ბოლოს კი პრაქტიკა თამაშად.

**ცოცხალი ვერსია:** https://thothcher.github.io/sumup-helper/

| საიტი | თემები | სტილი |
|---|---|---|
| [JS ფოთლები](js/) | ცვლადები, პირობები, ციკლები, ფუნქციები, კლასები, DOM, BOM, API | შემოდგომის ტყე, ცვენადი ფოთლები, მუსიკა |
| [React სტუდია](react/) | Components, State, Lists, Effects, Context, Router, Forms, Query | მშვიდი, ნათელი; დემოები ნამდვილ React-ზე |
| [Next.js Netrunner](nextjs/) | Rendering, Routing, Server, Data, Cache, Actions, API, Database, Auth | კიბერპანკი; სერვერის სიმულაციები |
| [Angular სიგნალი](angular/) | Components, Bindings, Signals, Control Flow, Inputs, Directives, Services, Router, HTTP | მკვეთრი, გრადიენტით; დემოები ნამდვილ Angular 22-ზე |

## პრაქტიკა: თამაში

ყოველ საიტს აქვს ერთი ფანჯარა დონეებით: ტესტი, ბაგის ძებნა, კოდის დალაგება და „რა მოხდება?“. JS ფოთლებს მეხუთე დონეც აქვს, „პროექტი“ (იხ. ქვემოთ).
სწორი პასუხი მონეტებს მოგიტანს, ზედიზედ სამი კი კომბოს. ყოველ დონეზე სამი გული გაქვს.
ბოლო გულზე რაღაც უცნაური ხდება... ეს საიდუმლოა.

**თემების ფილტრი.** ფანჯრის მარცხენა კიდეზე „თემები“ ჩანართია (ტელეფონზე ის სათაურის ზოლშია): აირჩიე, რომელი თემები შევიდეს თამაშში.
კითხვა მხოლოდ მაშინ ჩნდება, როცა მისი ყველა თემა არჩეულია, ტესტს კი მინიმუმ ორი თემა სჭირდება. დონე, რომელსაც ამ თემებზე კითხვები არ აქვს, გამოტოვდება.
არჩევანი ბრაუზერში ინახება, რეკორდი კი მხოლოდ ყველა თემით ითვლება.

## JS ფოთლები: შესვენება, პროექტი და ინგლისური

**☕ შესვენება.** ფოთლის გვერდით ყავის ღილაკია, ისევე როგორც ლექციების სლაიდებში. დააჭირე და ტყის ფონზე, ცვენადი ფოთლებით, 10 წუთის უკუთვლა გაიხსნება (±1 წუთი, „დამალვა“, „დასრულება“). ქვემოთ რადიოა: 7 ჟანრი და 29 სადგური (ჯაზი, ჩილი, ფოკუსი, კლასიკა, ელექტრონული, ინდი და როკი, საქართველო და მსოფლიო). სადგურის ჩავარდნისას იმავე ჟანრის შემდეგს ირჩევს. შესვენებისას ყანჩელის „ყვითელი ფოთლები“ ჩუმდება და ბოლოს თავისით ბრუნდება. დარჩენილი დრო ყავის ღილაკზე და ჩანართის სათაურშიც ჩანს, ბოლოს კი ზარი ისმის.
სადგურები `js/src/data/radio.js`-შია. ყველა Chrome-ში, https გვერდიდან გამოვცადე (2026 ოქტომბერი). SomaFM აქ არ არის: სხვა საიტებიდან ჩართვას კრძალავს (403). ახალი სადგურის დამატებისას ეს ჯერ გამოსცადე.

**მეხუთე დონე: „პროექტი“.** ეკრანზე რეალური ამოცანაა („მომხმარებლების სია სერვერიდან“, „ბნელი რეჟიმი“, „ლარის კონვერტერი“...). ჩართე თემები, რომლებიც მას დასჭირდება. თითოეულ თემასთან კითხვაა, მაგ. „მონაცემი სერვერიდან მოდის?“, და ამოცანის კითხვისას სწორედ ეს კითხვები უნდა დაუსვა საკუთარ თავს. შემოწმების შემდეგ ყველა თემას მიზეზი აქვს, ამოხსნის კოდი კი თემების ხატულებითაა მონიშნული და „გაუშვი“-ზე ხაზ-ხაზ, ნელა სრულდება. დონე დაცულია (გული არ იკარგება): „სურვილისამებრ“ თემა არც ამატებს და არც აკლებს, 0 / 1 / 2 შეცდომაზე კი +30 / +20 / +10 მონეტაა.
ამოცანები `js/src/data/projects.js`-შია. სწორი პასუხი ამოხსნის კოდიდან გამოდის: თემა საჭიროა, თუ უმცირეს ამოხსნაში რომელიმე ხაზი მის გარეშე ვერ იმუშავებს. ახალი ამოცანისას ყოველი ხაზი თემით მონიშნე და ყოველი თემა რამდენიმე ამოცანაში საჭირო, რამდენიმეში ცხადად ზედმეტი გახადე, თორემ გადამრთველები აზრს კარგავს.

**ინგლისური.** ყველაფერი ახალი (შესვენება, პროექტი, „დაიწყე დონიდან“) ქართულადაა, ინგლისური თარგმანი კი მის ქვემოთ. თამაშის სათაურის ზოლში „EN“ ღილაკი ინგლისურს მალავს ან აბრუნებს, არჩევანი ინახება. გვერდის დანარჩენი ტექსტი (თემები, ტესტები, ბაგები) ჯერ მხოლოდ ქართულია.

**დონიდან დაწყება.** თამაშის პირველ ეკრანზე შეგიძლია ნებისმიერი დონიდან დაიწყო, მაგ. ლექციაზე მეხუთის საჩვენებლად. რეკორდი მხოლოდ პირველი დონიდან დაწყებისას და ყველა თემით ითვლება.

## გაშვება

build არ სჭირდება: ეს უბრალოდ HTML, CSS და JavaScript-ია. გახსენი `index.html` Live Server-ით (ან ნებისმიერი სტატიკური სერვერით), მაგ.:

```bash
npx serve .
```

## სტრუქტურა

```
index.html          მთავარი გვერდი: ოთხი ბარათი
js/                 JS ფოთლები (შესვენება: break.js, break.css; პროექტი: level-project.js, project.css)
react/              React სტუდია (vendor/: React 18.3.1)
nextjs/             Next.js Netrunner
angular/            Angular სიგნალი
  ng/main.js        აწყობილი Angular დემოები (Angular Elements)
  demos-src/        მათი წყარო: Angular 22 workspace
```

ოთხივე საიტი ერთსა და იმავე თამაშის ძრავას იყენებს: `src/game.js` და `src/levels.js`.
React-ს, Next.js-ს და Angular-ს ასევე საერთო აქვთ `styles/base.css`; თითოეულის იერსახე `styles/theme.css`-შია.
ერთ-ერთის შეცვლისას ასლი დანარჩენებშიც გადაიტანე.

**ახლა ისინი ერთნაირი აღარ არის:** JS ფოთლებში `game.js` და `levels.js` გაფართოებულია (მეხუთე დონე, „დაიწყე დონიდან“), React-ში, Next.js-სა და Angular-ში კი ჯერ ძველი ვერსიაა. გადატანისას `game.js`, `levels.js` და `game.css`-ის ახალი ნაწილი გადაიტანე, `index.html`-ში კი `lang.js`, `level-project.js` და `data/projects.js` (იმ საიტის თემებისა და ამოცანებით) დაამატე.

ყოველ კითხვას თემა აქვს: `QUIZ`-ში `answer`, `BUGS`-ში და `OUTPUTS`-ში `topic`, `PUZZLES`-ში `topics`. ახალი კითხვის დამატებისას თემა არ დაგავიწყდეს, თორემ ფილტრი მას ვერ იპოვის.

## Angular-ის დემოები

Angular build-ის გარეშე ვერ იმუშავებს, ამიტომ მისი დემოები `angular/demos-src/`-შია (Angular 22, zoneless) და წინასწარ იკრიბება ერთ ფაილად, `angular/ng/main.js`. იქ Angular Elements ყოველ კომპონენტს custom element-ად არეგისტრირებს (`<ng-demo-signals>` და ა.შ.), გვერდი კი მათ ჩვეულებრივ HTML ტეგებად იყენებს.

დემოს შეცვლის შემდეგ:

```bash
cd angular/demos-src
npm install
npx ng build      # → angular/ng/main.js
```
